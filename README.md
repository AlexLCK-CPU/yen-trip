# 旅費換算

給長輩去旅行用的換算 App：一行港幣、一行外幣，打任何一行另一行即刻計。
加到 iPhone 主畫面即可當 App 用，可離線（用上次存落嘅滙率）。

## 用法

- 上面一行係外幣（預設日圓，可按貨幣名轉做台幣／韓圜／人民幣……）。
- 下面一行永遠係港幣。
- 喺任何一行打字，另一行自動計出等值。
- 紅色「重設」掣：清空兩行，游標返到上面一行。
- 「更新」掣：即時抓最新滙率；抓唔到會顯示「暫時用上次滙率」。

## 滙率來源

- 主要：open.er-api.com（每日更新，免登記）
- 後備：jsDelivr 上嘅 currency-api（@fawazahmed0）
- 兩者都連唔到：用瀏覽器存落嘅上一次滙率；第一次就用手機內建嘅保底牌價。

## 加到 iPhone 主畫面

用 Safari 開網址 → 分享掣 → 加入主畫面。
